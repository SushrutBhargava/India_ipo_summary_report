## Derived / cross-checked valuation figures
- RHP's own Basis for Offer Price EPS: FY26 Basic ₹12.01, Diluted ₹11.78 (p6558-6577); weighted average diluted EPS across 3 years = ₹9.74.
- chittorgarh's IPO Valuation table: EPS Pre ₹12.28, EPS Post ₹9.60, P/E Pre 9.04x, P/E Post 11.56x, Market Cap ₹211.55 Cr pre / ₹270.69 Cr post.
- chittorgarh's EPS Pre of ₹12.28 = FY26 PAT ₹2,340.42 lakh / 1,90,58,755 pre-issue shares = ₹12.28 — internally consistent with chittorgarh's own share count, just uses a plain per-share-count division rather than the RHP's own weighted-average-with-bonus-adjustment EPS convention (₹12.01 basic / ₹11.78 diluted). Both are legitimate EPS calculation conventions; they differ by about 2%.
- Using RHP's own diluted EPS (₹11.78) against ₹111: pre-issue P/E = 9.42x, close to chittorgarh's 9.04x.
- Post-issue EPS ₹9.60 = FY26 PAT ₹2,340.42 lakh / 2,43,86,755 post-issue shares = ₹9.60 — matches chittorgarh exactly.
- Post-issue P/E = 111/9.60 = 11.56x — matches chittorgarh.
- NAV: RHP's Basis for Offer Price shows FY26 NAV ₹47.43, but chittorgarh's KPI table shows ₹35.02 (the FY25 NAV) — same staleness bug as above. Using the correct FY26 NAV of ₹47.43, P/BV at ₹111 = 2.34x, not chittorgarh's stated 3.17x (which uses the stale ₹35.02 FY25 NAV: 111/35.02=3.17, confirming the source of the discrepancy).
