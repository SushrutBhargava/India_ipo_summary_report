# IPO Ledger Task

Daily automated research ledger tracking Indian mainboard + SME IPOs — fundamentals, subscription, GMP, listing-day risk.

**Last run: 21 October 2026 (10:30 AM IST)** — 2026-10-21 IST / 2026-10-21 UTC (see Run Log below for details).

## What it does

Cron job **"IPO Ledger + Trading News Briefing"** (`74f7c0f6c212`) runs daily at **15:30 IST**, three tasks in sequence:

1. **IPO Fundamentals Ledger** — rebuilds [[ipo-fundamentals-ledger.html]] (also mirrored to `index.html` for GitHub Pages). Pulls DRHP/RHP financials, valuation, subscription, fund usage from chittorgarh.com, nseindia.com, bseindia.com, investorgain.com. Never fabricates undisclosed figures — marks them "pending".
2. **Trading news briefing** — runs the `tdesk` CLI for high-impact news, economic calendar, and watchlist/position-tagged headlines.
3. **IPO listing-day risk desk** — advisory-only report (`listing-risk-desk-<date>.md`): GMP/subscription anomaly flags, anchor lock-in unlock-ratio risk, a 0–100 risk score, and a conditional hold/exit recommendation. **Never places or simulates real orders** — text advisory only.

## Data sources

- chittorgarh.com — primary financials, DRHP/RHP cross-check, subscription
- nseindia.com / bseindia.com — price bands, live subscription (via curl, browser is Akamai-blocked)
- investorgain.com — live GMP (browser_exec, JS-rendered)
- **Fyers broker API** (added 16 Sep 2026) — live last-traded price for already-listed issues + holdings-aware flag. Read-only: quotes/holdings/positions/funds only, **no order-placement endpoints ever called**. Auth via TOTP silent login (`~/.hermes/scripts/fyers_auth.py`), credentials in `~/.fyers/credentials.json` (never typed into chat).
